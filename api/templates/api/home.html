  • Swagger API Documentation

    • REST API Endpoints

    • GET http://127.0.0.1:8000/api/listings/ - return a paginated list of all Airbnb listings
      http://127.0.0.1:8000/api/listings/

    • POST http://127.0.0.1:8000/api/listings/ - create a new Airbnb listing
      http://127.0.0.1:8000/api/listings/

    • PUT http://127.0.0.1:8000/api/listings/<id>/ - fully update an existing listing
      http://127.0.0.1:8000/api/listings/1/

    • DELETE http://127.0.0.1:8000/api/listings/<id>/ - delete an existing listing
      http://127.0.0.1:8000/api/listings/1/

    • GET http://127.0.0.1:8000/api/listings/borough/<borough>/ - filter listings by borough
      Example: http://127.0.0.1:8000/api/listings/borough/Manhattan/

    • GET http://127.0.0.1:8000/api/listings/under-price/<price>/ - filter listings priced under a particular value
      Example: http://127.0.0.1:8000/api/listings/under-price/100/
